# gsm.reporting: Good Statistical Monitoring Reporting

The Good Statistical Monitoring or 'gsm' suite of R packages provides a
framework for statistical data monitoring. 'gsm.reporting' provides
workflows to generate the reporting data model needed to generate
reports.
